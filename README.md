### 🌌 关于我 (About Me)

你好，我是 **Ryu6**，一个疯狂的王座、后现代自我批判防止被批判的风味嘉豪、自命不凡却默默无名的作家与程序员、没人在乎也想留下些思想的普通青年。

我正在制作一个世界观以及人生第一款游戏，在技术这条路上还只是个小学生，学无止境，欢迎交流技术思路共同进步。

- **喜欢的**：ACG文化产品、小岛秀夫、宫崎英高、三上真司、板垣伴信、稻船敬二（洛克人时期）、横尾太郎、奈须蘑菇、约翰卡马克、CDPR、拉瑞安、西木工作室等。
- **讨厌的**：内卷、优绩主义、社达理论和无脑的商业化工业垃圾。
